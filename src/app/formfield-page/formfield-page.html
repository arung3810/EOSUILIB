Form Fields Component

Form Input Fields

A collection of form input components with validation and styling

Component Properties

Property Type Default Description
label string - Field label text
placeholder string - Input placeholder text
type 'text' | 'email' | 'password' | 'number' | 'tel' 'text' Input field type
required boolean false Mark field as required
disabled boolean false Disable field interaction
error string - Error message to display
value string '' Input field value

Events

Event Type Description
valueChange EventEmitter<string> Emitted when input value changes
blur EventEmitter<void> Emitted when input loses focus
focus EventEmitter<void> Emitted when input gains focus

Features

  • Built-in validation support
  • Error message display
  • Disabled state styling
  • Required field indicators
  • Consistent styling across form elements
