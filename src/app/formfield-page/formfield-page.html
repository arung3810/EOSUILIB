Available Components

1. Text Input Component

Supports text, email, number, and date inputs

<lib-text-input
  label="Name"
  placeholder="Enter your name"
  formControlName="name">
</lib-text-input>

2. Textarea Component

Multi-line text input

<lib-textarea
  label="Description"
  placeholder="Enter description"
  [rows]="4"
  formControlName="description">
</lib-textarea>

3. Select Component

Dropdown selection with options

<lib-select
  label="Country"
  [options]="countryOptions"
  formControlName="country">
</lib-select>

4. Toggle Component

Switch/toggle for boolean values

<lib-toggle
  label="Enable notifications"
  formControlName="notifications">
</lib-toggle>

5. Radio Group Component

Radio button group

<lib-radio-group
  label="Gender"
  [options]="genderOptions"
  formControlName="gender">
</lib-radio-group>

6. Checkbox Group Component

Multiple checkbox selections

<lib-checkbox-group
  label="Interests"
  [options]="interestOptions"
  formControlName="selectedInterests">
</lib-checkbox-group>

7. Input With Icon Component

Input with icon/prefix/suffix

<lib-input-with-icon
  label="Amount"
  icon="₹"
  type="number"
  placeholder="Enter amount"
  formControlName="amount">
</lib-input-with-icon>

Common Properties

Property Type Default Description
label string '' Label text displayed above the control
disabled boolean false Disable the form control
placeholder string '' Placeholder text (text inputs, textarea)
type string 'text' Input type: 'text', 'email', 'number', 'date' (text input)
options Array [] Options array (select, radio, checkbox)
rows number 3 Number of visible rows (textarea)
icon string '₹' Icon/prefix text (input-with-icon)
iconPosition 'left' | 'right' 'left' Icon position (input-with-icon)

Import Components

All form controls can be imported from 'eos-comp':

import {{ '{' }}
  TextInputComponent,
  TextareaComponent,
  SelectComponent,
  ToggleComponent,
  RadioGroupComponent,
  CheckboxGroupComponent,
  InputWithIconComponent
{{ '}' }} from 'eos-comp';

Features

  • ✓ Standalone components - No module imports required
  • ✓ ControlValueAccessor implementation - Full Angular Forms integration
  • ✓ Works with Reactive Forms and Template-Driven Forms
  • ✓ Type-safe interfaces for options (SelectOption, RadioOption, CheckboxOption)
  • ✓ Consistent styling across all components
  • ✓ Support for disabled state
  • ✓ Built-in validation support
  • ✓ Accessible with proper label associations

Usage Example

// Component TypeScript
export class MyFormComponent {{ '{' }}
  form = this.fb.group({{ '{' }}
    name: [''],
    email: [''],
    country: ['us'],
    notifications: [false]
  {{ '}' }});

  countries: SelectOption[] = [
    {{ '{' }} value: 'us', label: 'United States' {{ '}' }},
    {{ '{' }} value: 'uk', label: 'United Kingdom' {{ '}' }}
  ];
{{ '}' }}

// Template
<form [formGroup]="form">
  <lib-text-input label="Name" formControlName="name"></lib-text-input>
  <lib-text-input label="Email" type="email" formControlName="email"></lib-text-input>
  <lib-select label="Country" [options]="countries" formControlName="country"></lib-select>
  <lib-toggle label="Notifications" formControlName="notifications"></lib-toggle>
</form>
