TabPane Component

Tab Navigation

A tabbed interface for organizing content into separate views

Component Properties

Property Type Default Description
tabs Array<TabConfig> required Array of tab configurations
activeTab number 0 Index of initially active tab

Tab Configuration

Property Type Description
label string Tab label text
content string | TemplateRef Tab content to display
disabled boolean Disable tab interaction

Events

Event Type Description
tabChange EventEmitter<number> Emitted when active tab changes
