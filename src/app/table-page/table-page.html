Table Component

Data Table with Pagination

A feature-rich table component with sorting and pagination

Component Properties

Property Type Default Description
columns Array<ColumnConfig> required Array of column configurations
rows Array<any> required Array of row data objects
total number 0 Total number of rows for pagination
page number 1 Current page number
pageSize number 10 Number of rows per page

Events

Event Type Description
pageChange EventEmitter<number> Emitted when page changes
sortChange EventEmitter<SortEvent> Emitted when column sort changes

Column Configuration

Property Type Description
field string Data field key
header string Column header text
sortable boolean Enable sorting for column
width string Column width (e.g., '150px', '20%')
