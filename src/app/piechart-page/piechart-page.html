Component Properties

Property Type Default Description
data ChartData[] required Array of chart data with label, value, and optional color
type 'pie' | 'donut' 'pie' Chart type - pie or donut
width number 380 Chart width in pixels
height number 350 Chart height in pixels
showLegend boolean true Show/hide legend
showLabels boolean true Show/hide data labels on chart
showTooltip boolean true Enable/disable tooltips on hover
donutSize string '65%' Inner hole size for donut charts (percentage)
colors string[] ['#5B93FF', '#FFD66B', '#FF8B81', '#7FCDA4'] Array of color hex codes for chart segments
