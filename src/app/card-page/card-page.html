Asset Card Specific Properties

Property Type Default Description

assetLegendData Array<{{ '{' }}label, percentage, color{{ '}' }}> required Legend data for the chart

assetChartWidth number 260 Chart width in pixels

simulationPeriod string - Simulation period text

FWP Generate Card Specific Properties

Property Type Default Description
fwpTitle string 'FWP Generated' Main title displayed at the top of the card
fwpSubtitle string 'Last generated on 19 January, 2026' Subtitle text shown below the title
fwpPreviewText string 'Preview' Text displayed on the preview button
fwpGenerateText string 'Generate FWP' Text displayed on the generate button
fwpPreviewDisabled boolean false Disables the preview button when set to true
fwpGenerateDisabled boolean false Disables the generate button when set to true

FWP Generate Card Events

Event Type Description
fwpPreviewClick EventEmitter<void> Emitted when the Preview button is clicked
fwpGenerateClick EventEmitter<void> Emitted when the Generate FWP button is clicked

n3xt3month Card Specific Properties

Property Type Default Description
n3xt3monthTitle string - Title text displayed above the value (e.g., "Surplus for the Period")
n3xt3monthValue string - Main value displayed prominently (e.g., "₹1,43,818")
n3xt3monthIcon string - SVG markup as string for the icon (displayed on the left side)

Nominee Card Specific Properties

Property Type Default Description
nomineeTitle string 'Investment Nominees' Main title displayed at the top of the card
nomineeSubtitle string 'Nominees' Subtitle text shown above the nominee list
nomineeHeaderIcon string - SVG markup as string for the header icon (displayed next to title)
nomineeList Array<{{ '{' }}name, relation, initials, avatarColor?{{ '}' }}> required Array of nominee objects. Each nominee must have:
• name (string): Nominee's full name
• relation (string): Relationship to the user
• initials (string): Initials for avatar (1-2 characters)
• avatarColor (string, optional): Hex color for avatar background (defaults to #5FA897)

Will Card Specific Properties

Property Type Default Description
willCardLabel string - Label text displayed at the top (e.g., "Total Investment")
willCardValue string - Main value displayed below the label (e.g., "₹5,61,43,544")
willCardIcon string - URL path to icon image file. Use this for image files.
willCardSvgIcon string - SVG markup as string for inline icon. Use this for SVG icons.

Tax Income Overview Card Properties

Property Type Default Description
taxIncomeChartData ChartData[] required Chart data for the income donut chart
taxIncomeItems Array<{{ '{' }}label, value, color, icon?, tooltipData?{{ '}' }}> required Income items with labels, values, colors, optional icons, and optional tooltip data.

Tooltip Feature:
• Add icon (SVG string) to display an info icon
• Add tooltipData with title and items[]
• Each item can have label, value, and optional subtext
• See the "Additional Income" example in card-page.ts
grossIncome string - Total gross income displayed in the center
taxIncomeChartWidth number 350 Chart width in pixels
taxIncomeChartHeight number 350 Chart height in pixels
taxIncomeChartColors string[] ['#5B93FF', '#7FCDA4', '#FFD66B'] Array of color hex codes for chart segments
taxIncomeDonutSize string '65%' Inner hole size for the donut chart
taxIncomeChartShowTooltip boolean false Enable/disable chart tooltips on hover
