Tooltip Component

Basic Tooltip

Hover over the icon to see the tooltip

Component Properties

Property Type Default Description
tooltipText string required Text to display in tooltip
position 'top' | 'bottom' | 'left' | 'right' 'top' Tooltip position relative to trigger

Usage

The tooltip component displays helpful information when users hover over an element. It's commonly used for providing additional context or explanations without cluttering the interface.
