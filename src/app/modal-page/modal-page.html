Component Properties

Property Type Default Description
open boolean false Controls modal visibility
position 'left' | 'right' | 'center' 'center' Modal position - 'center' for popup, 'left'/'right' for sidebars
title string - Modal title text (optional)
message string - Modal message/content text (optional)
button1 string - Primary button label (optional)
button2 string - Secondary button label (optional)
size 'sm' | 'md' | 'lg' | 'xl' 'md' Modal size (applies to center modals)
closeOnBackdrop boolean true Close modal when clicking backdrop
hideCloseButton boolean false Hide close button
showHeader boolean true Show/hide modal header
showFooter boolean false Show/hide modal footer
closeOnEscape boolean true Allow closing modal with Escape key

Events

Event Type Description
openChange EventEmitter<boolean> Emitted when modal open state changes
click1 EventEmitter<MouseEvent> Emitted when primary button is clicked
click2 EventEmitter<MouseEvent> Emitted when secondary button is clicked
closed EventEmitter<void> Emitted when modal is fully closed (after animation)

Usage Examples

Center Modal (Popup)

<lib-modal
  [open]="isModalOpen()"
  heading="Modal Title"
  position="center"
  size="md"
  [showHeader]="true"
  [showFooter]="true"
  [closeOnEscape]="true"
  [closeOnBackdrop]="true"
  (openChange)="onModalOpenChange($event)">

  <div modal-body>
    <p>Your dynamic content goes here</p>
  </div>

  <div modal-footer>
    <button class="btn btn-outline-dark">Cancel</button>
    <button class="btn btn-dark">Save</button>
  </div>
</lib-modal>

Right Sidebar

<lib-modal
  [open]="isSidebarOpen()"
  heading="Sidebar Title"
  position="right"
  (openChange)="onSidebarOpenChange($event)">

  <div modal-body>
    <p>Sidebar content here</p>
  </div>
</lib-modal>

Left Sidebar

<lib-modal
  [open]="isLeftSidebarOpen()"
  heading="Navigation"
  position="left"
  (openChange)="onLeftSidebarOpenChange($event)">

  <div modal-body>
